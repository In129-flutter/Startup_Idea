# 🚀 Startup Ideas App

A Flutter app to submit, list, and vote on innovative startup ideas.  
Users can share their concepts, explore others’ ideas, and see which ones rank the highest.

---

## 📱 App Description
Startup Ideas App lets aspiring entrepreneurs share their startup concepts with the world.  
Users can:
- Submit their own idea with a **name**, **tagline**, and **description**.
- View all submitted ideas.
- Upvote ideas they like.
- Check the **Leaderboard** to see the top-voted ideas.

---

## 🛠 Tech Stack
- **Flutter** (Dart) – Cross-platform app framework.
- **Material Design** – UI components.
- **Shared Preferences** – Local storage for saving ideas and votes.

---

## ✨ Features Implemented
- Light & Dark mode toggle 🌙☀️
- Idea submission form.
- List of all ideas.
- Leaderboard showing top 5 ideas by votes.
- Local data storage (offline support).
- Custom app logo.
